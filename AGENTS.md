# Набор шаблонов для задач

Это исходники переносимого набора, а не обязательная родительская папка проектов.

- Пиши по-русски, кратко и предметно.
- Git и управление версиями остаются пользователю; Git-команды не выполняй.
- Правила создаваемых проектов хранятся в templates/task/AGENTS.md.
- Скиллы находятся в .agents/skills; установка создаёт ссылки в ~/.agents/skills.
- Не перезаписывай существующие инструкции и пользовательские скиллы.
- Проверяй изменения скрипта командой python3 -B -m unittest discover -s tests -v.
