# Начало задачи

Корень workspace находится на три уровня выше директории этого скилла.
Прочитай его AGENTS.md. Все команды ниже выполняются из этого корня.

Выбери короткое имя папки из слов запроса (латиница, цифры, дефисы).
Если тему невозможно понять, спроси её; в остальных случаях сообщи выбранное имя
и продолжай без дополнительного согласования.

Выполни:

```sh
python3 scripts/workspace.py new task-name --title "Название задачи"
```

Скрипт создаёт projects/task-name с четырьмя файлами контекста и artifacts/.
Существующая задача не перезаписывается. Если пользователь хочет продолжить её,
прочитай существующие файлы.

Внеси известные цель, контекст, ограничения и критерии готовности в BRIEF.md.
Неизвестное оставь открытыми вопросами. Локальные особенности внеси в AGENTS.md,
следующий шаг — в STATE.md. Не добавляй общие правила повторно.

Покажи путь к задаче и следующий шаг.
