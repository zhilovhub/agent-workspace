# Начало задачи

По умолчанию используй текущую рабочую директорию пользователя. Другую директорию
используй, если он её указал. Не создавай дополнительную папку projects/ или
вложенную папку по названию задачи без запроса.

Найди исходный каталог набора по пути этого SKILL.md: сначала разреши символическую
ссылку, затем поднимись на три уровня от директории скилла.
Там находятся scripts/workspace.py и templates/task/. Не используй расположение
шаблонов как директорию новой задачи.

Прочитай применимые инструкции в целевой директории и проверь её непосредственное
содержимое. Если контекст задачи уже существует, продолжай по нему; не запускай
повторную инициализацию. При конфликте отдельного файла (например, существующего
AGENTS.md) согласуй объединение правил, сохраняя исходное содержимое.

Вызови скрипт с абсолютными путями к нему и к выбранной директории, например:

```sh
python3 /path/to/agent-workspace/scripts/workspace.py init /path/to/task --title "Название задачи"
```

Скрипт создаёт AGENTS.md, BRIEF.md, STATE.md, DECISIONS.md, SKILLS.md и artifacts/.
Существующие контекстные файлы не перезаписываются; прочие файлы сохраняются.
Если скрипт недоступен, сообщи об этом; не утверждай, что workspace создан.

Прочитай созданный AGENTS.md. Внеси известные цель, контекст, ограничения и критерии
готовности в BRIEF.md. Неизвестное оставь открытыми вопросами.
Особенности задачи запиши в AGENTS.md, следующий шаг — в STATE.md.

Покажи путь к задаче и следующий шаг. Git-команды не выполняй.
