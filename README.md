# Контекст задач для Codex

Один набор шаблонов и три пользовательских скилла. Проект можно начать в любой
директории — она не обязана находиться внутри этого набора.

## Один раз на устройстве

Положи набор в удобное место и установи скиллы:

```sh
python3 ~/agent-workspace/scripts/workspace.py install
```

Установщик создаёт три символические ссылки в ~/.agents/skills/.
Существующие чужие скиллы сохраняет, повторный запуск ничего не дублирует.
Глобальный AGENTS.md и настройки Codex не меняются. Нужны Python 3.9+ и Codex.

[Codex поддерживает пользовательские скиллы и ссылки на их папки](https://learn.chatgpt.com/docs/build-skills).
Открой новую сессию и проверь через /skills: task-start, context-sync, context-handoff.
Если скиллы не появились, перезапусти Codex.

## Начать задачу где угодно

```sh
mkdir -p ~/tasks/kitchen
cd ~/tasks/kitchen
codex
```

Скажи: «Давай начнём задачу: спланировать ремонт кухни».

Агент создаст прямо в kitchen/:

```text
AGENTS.md
BRIEF.md
STATE.md
DECISIONS.md
SKILLS.md
artifacts/
```

Затем заполнит известную постановку и уточнит открытые вопросы.
Если автоматический выбор скилла не сработал, напиши:
«Используй $task-start: спланировать ремонт кухни».

Новая вложенная папка не создаётся. Можно явно указать другую директорию.
Посторонние файлы сохраняются. Если уже есть контекст, агент продолжит по нему.
При конфликте, например с существующим AGENTS.md, скрипт ничего не перезапишет;
агент согласует объединение правил.

## Работа

| Фраза | Результат |
| --- | --- |
| Давай сформулирую задачу и контекст… | BRIEF.md и особенности в AGENTS.md |
| Я сделал то-то без тебя | STATE.md с отметкой источника сведений |
| Подготовь новый диалог | Актуальный контекст и первое действие для продолжения |
| Я восстановил контекст такой-то ревизии | Перечитывание файлов и сверка с артефактами |

Версии, коммиты и публикацию ведёшь ты. Git-команды в процедуру не входят.

AGENTS.md содержит правила и стиль, BRIEF.md — постановку,
STATE.md — текущее состояние, DECISIONS.md — решения и причины.
SKILLS.md — краткий каталог; подробные результаты складываются в artifacts/.

В новом диалоге открой папку задачи и напиши:

> Продолжаем эту задачу. Прочитай AGENTS.md, BRIEF.md и STATE.md,
> сверь их с артефактами и начни с раздела «Продолжение».

Агент предлагает переход при завершении этапа, смене подзадачи или накоплении
лишнего обсуждения. Точную заполненность контекстного окна он не обещает.

## Шаблоны и перенос

Исходные правила находятся в templates/task/AGENTS.md, скиллы — в .agents/skills/.
Правки шаблонов применяются к новым задачам. В существующих задачах правила
остаются самостоятельными файлами; их обновление выполняется отдельно.

Для другого устройства перенеси набор целиком и повтори install.
Папки задач можно переносить независимо: их контекст не ссылается на исходный
каталог набора. Для автоматических процедур на новом устройстве установи скиллы.
Способ хранения и синхронизации выбираешь ты.

Ссылки установки указывают на расположение набора. Если переносишь сам набор на
этом устройстве, сначала удали только три ранее созданные ссылки, затем повтори
install из нового места. Установщик не заменяет существующие ссылки автоматически.

[Codex читает инструкции из AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md).
Запускай его из папки задачи; более общие инструкции окружения также продолжают
действовать. SKILLS.md служит каталогом и ничего не устанавливает.

## Ручной запуск и проверка

Из любой директории:

```sh
python3 ~/agent-workspace/scripts/workspace.py init . --title "Моя задача"
```

Для проверки самого набора:

```sh
cd ~/agent-workspace
python3 -B -m unittest discover -s tests -v
```

Тесты используют временные папки и не меняют пользовательские скиллы.
