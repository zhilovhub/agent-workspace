# Скиллы

| Скилл | Назначение |
| --- | --- |
| task-start | Создать контекст задачи в выбранной директории |
| context-sync | Учесть работу агента или пользователя, обновить постановку |
| context-handoff | Подготовить новый диалог или продолжить после восстановления контекста |

Скиллы устанавливаются для пользователя в ~/.agents/skills/; инструкция каждого —
SKILL.md в одноимённой папке. Используй путь из каталога текущей сессии Codex.
Если скилл недоступен, следуй AGENTS.md и сообщи об отсутствии скилла.

Другие доступные скиллы определяются текущей сессией. Применяй подходящие по задаче,
не загружая все инструкции сразу. Этот каталог сам по себе ничего не устанавливает.
